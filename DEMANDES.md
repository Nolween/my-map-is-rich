# Les demandes des joueurs

Le registre des commentaires de la page CurseForge de My Map Is Rich ([les commentaires](https://www.curseforge.com/wow/addons/my-map-is-rich-forever/comments)), tenu par la commande `/demandes-commentaires` de Claude Code (`.claude/skills/demandes-commentaires/`). Un commentaire n'y est jugé qu'une fois ; sa ligne change quand une réponse arrive ou quand la demande est faite.

Verdicts : **À faire**, **À faire autrement**, **Déjà là**, **À creuser**, **À décliner**. La « Suite » dit ce qui en a été fait (répondu, version qui l'apporte).
